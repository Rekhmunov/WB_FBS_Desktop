# Анализ: desktop-порт «Поставки — ВБ ФБС»

## Стек (зафиксирован)

| Компонент | Выбор | Причина |
|-----------|--------|---------|
| Python | **3.8.x** | Последняя ветка с поддержкой Windows 7 |
| UI | **PyQt5** | Qt5 работает на Win7; Qt6/PySide6 — только Win10+ |
| БД | **SQLite** | Полностью локально, без сервера |
| Сеть | только API WB | Marketplace + Content; веб FeedPilot не трогаем |

## Scope

**Включено:** источники, товары, категории, ручной sync **по всем источникам**, вкладки Новые/На сборке/В доставке, оценка палет после sync, МГТ (create/add/choose), создание/добавление в поставку, «выбрать все подходящие», поиск заказа (локально + WB), карточка поставки (лист подбора summary/extended с фото, стикеры 58×40, стикеры по категориям, TRBX, QR, отменённые, портал ВБ, обновление статусов КИЗ), маркировка, проверка ШК.

**Исключено:** ТСД, Вывод КИЗ / Честный знак / CryptoPro / Analytics, блок автоматики (шестерёнка / автосинк / автосбор МГТ).

## Зависимости настроек

- **Источники** — имя с «ФБС»/FBS + токен Marketplace (и Контент для названий).
- **Товары** — артикул/nmID, фото, `box_qty`, категория, `skip_kiz_gtin_check`.
- **Категории** — `boxes_per_pallet` для оценки палет и печати по категориям.

## Изоляция от веба

Каталог `desktop_wb_fbs/` — отдельное приложение. Файлы `review_processor/`, `web_*` в этой ветке не меняются.

## UI parity (дизайнерский критерий)

Визуальный язык блока «Поставки — ВБ ФБС» снят с `main` (`.wb-fbs-*` в `web_static/style.css` + разметка `#section-supplies-wb-fbs`):

- светлый фон `#f7fbff`, панели с бордером `#d9e8f7` / `#d7e0ef`, radius 8–16px;
- primary blue `#2563eb`, secondary светлые, МГТ `#9810fa`;
- вкладки с нижней линией + счётчики; sync-info ok/error; нижняя bar выбора;
- карточка поставки: header / chips / split-кнопки (лист подбора, стикеры) как в вебе.

Осознанные отличия продукта (не UI): нет ТСД, Вывода КИЗ, шестерёнки автоматики.
