ЭДО - Контур.Логистика

                

                  эТрН уходит в API Контур.Логистика, Заявка (ЭЗЗ) — через Диадок.
                  Подпись — КриптоПро ЭЦП в браузере при отправке.
                

              

              
            


            
эТрН — API Контур.Логистика

            

              Нужен только API-ключ (x-kontur-apikey): отправка титула и статус перевозки.
            

            

              

                
                
                
              

            


            
Заявка (ЭЗЗ) — Диадок

            

              По документации Диадок: Client ID + логин/пароль для авторизации,
              From/To BoxId — ящики отправителя и перевозчика для PostMessage и статуса.
            

            

              

                
                
              

              

                
                
              

              

                
                
                
              

              

                
                
              

              

                
                
              

            


            
Подпись (необязательно)

            

              Отпечаток только подставляет сертификат в модалке отправки. Без него сертификат выбирается вручную.
            

            

              

                
                
              

            


            

              
              
              
            

          

        


        

          

            

              

                
Честный знак

                

                  Для вывода/возврата КИЗ после продаж WB FBS. Отчёт WB — отдельный токен
                  категории «Аналитика» (можно только чтение). В ЧЗ — через УКЭП в браузере.
                  КПП и ФИАС должны совпадать с действующим МОД в профиле Честного знака
                  (иначе документ примут, но обработают с ошибкой). Если поля пустые —
                  подставляются из юр. лица с тем же ИНН.
